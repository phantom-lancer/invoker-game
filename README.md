# Тренажёр Инвокера

Браузерный тренажёр Invoker из Dota 2. Один файл, работает офлайн, без регистрации и без зависимостей.

**Играть:** откройте `index.html` в браузере — всё уже внутри файла, интернет не нужен.

## Управление

| Клавиша | Действие |
|---|---|
| `Q` | Quas |
| `W` | Wex |
| `E` | Exort |
| `R` | Invoke |
| `Space` | старт / рестарт |
| `Esc` | выйти в меню (в «Бесконечном» — остановить разбор) |

Клавиши переназначаются в настройках — игра запоминает **физические** клавиши, поэтому работает на любой раскладке. На телефоне — тапы по сферам.

## Звук

Два набора, переключаются в настройках или кнопкой-динамиком в верхней панели:

- **Dota** — лёд, искра и огонь на сферах, плюс свой голос у каждого заклинания: Chaos Meteor гудит и свистит, Ice Wall звенит кристаллом, Sun Strike сначала свистит и падает с грохотом, Tornado завихряется шумом, Deafening Blast бьёт по ушам.
- **Синтез** — прежние чистые электронные блипы.
- **Выкл** — тишина.

Всё синтезируется в браузере, аудиофайлов нет.

## Режимы

- **На время** — все 10 заклинаний в случайном порядке под таймер.
- **Бесконечный** — случайные заклинания без финиша, для разминки.
- **Комбо-цепочки** — реальные связки (Wombo combo, Ice Wall → Chaos Meteor и другие) с подсчётом лишних нажатий.

## Подсказки

Три уровня, переключаются в настройках:

| Уровень | Что видно |
|---|---|
| Полные | иконка, название и комбинация |
| Вслепую | иконка и название — память на сочетания |
| Только иконка | только картинка, название скрыто, цепочка не светит будущие спеллы |

## Мелочи, которые есть

- Личный рекорд по каждому спеллу отдельно — видно прямо над целью.
- Полоса прогресса заезда и лента последних кастов.
- Когда комбинация уже собрана — Invoke загорается и пульсирует: можно кастовать не глядя.
- Разбор после заезда: где завис, где накосячил, график последних попыток.
- Статистика на старте: лучшее время, заездов, кастов всего, сколько спеллов в базе рекордов.
- Кнопка звука, кнопка «Меню», `Esc`, переназначение клавиш, сброс статистики. Всё хранится в браузере.

> Хранилище браузера привязано к адресу: прогресс на `github.io` и на файле с диска — разные ящики и они не переносятся друг в друга.

## Как считается оценка

Очередь сфер работает как в Dota: Invoke не обнуляет её, четвёртое нажатие выталкивает самую старую сферу. Поэтому следующий спелл часто стоит одного нажатия. **Par** — теоретический минимум нажатий для текущего заезда, **эффективность** — `par / твои нажатия`. 100% значит, что ни одного лишнего.

## Комбинации

| Заклинание | Сферы |
|---|---|
| Cold Snap | QQQ |
| E.M.P. | WWW |
| Sun Strike | EEE |
| Ghost Walk | QQW |
| Ice Wall | QQE |
| Tornado | QWW |
| Alacrity | WWE |
| Forge Spirit | QEE |
| Chaos Meteor | WEE |
| Deafening Blast | QWE |

Порядок сфер не важен: QQW, QWQ и WQQ — это один и тот же Ghost Walk.

## Для разработчика

`index.html` собирается из `dev/game.template.html`: скрипт `dev/build.ps1` вшивает картинки из `dev/assets` как base64. Правь шаблон, потом:

```powershell
powershell -ExecutionPolicy Bypass -File dev\build.ps1
```
