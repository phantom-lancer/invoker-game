# Тренажёр Инвокера

Браузерный тренажёр Invoker из Dota 2. Один файл, работает офлайн, без регистрации и без зависимостей.

**Играть:** откройте `index.html` в браузере — всё уже внутри файла, интернет не нужен.
https://phantom-lancer.github.io/invoker-game/

## Управление

| Клавиша | Действие |
|---|---|
| `Q` | Quas |
| `W` | Wex |
| `E` | Exort |
| `R` | Invoke |
| `Space` | старт / рестарт |

Клавиши переназначаются в настройках — игра запоминает **физические** клавиши, поэтому работает на любой раскладке. На телефоне — тапы по сферам.

## Режимы

- **На время** — все 10 заклинаний в случайном порядке под таймер.
- **Бесконечный** — случайные заклинания без финиша, для разминки.
- **Комбо-цепочки** — реальные связки (Wombo combo, Ice Wall → Chaos Meteor и другие) с подсчётом лишних нажатий.

## Как считается оценка

Очередь сфер работает как в Dota: Invoke не обнуляет её, четвёртое нажатие выталкивает самую старую сферу. Поэтому следующий спелл часто стоит одного нажатия. **Par** — теоретический минимум нажатий для текущего заезда, **эффективность** — `par / твои нажатия`. 100% значит, что ни одного лишнего.

## Комбинации

| Заклинание | Сферы |
|---|---|
| Cold Snap | QQQ |
| E.M.P. | WWW |
| Sun Strike | EEE |
| Ghost Walk | QQW |
| Ice Wall | QQE |
| Tornado | QWW |
| Alacrity | WWE |
| Forge Spirit | QEE |
| Chaos Meteor | WEE |
| Deafening Blast | QWE |

Порядок сфер не важен: QQW, QWQ и WQQ — это один и тот же Ghost Walk.

## Для разработчика

`index.html` собирается из `dev/game.template.html`: скрипт `dev/build.ps1` вшивает картинки из `dev/assets` как base64. Правь шаблон, потом:

```powershell
powershell -ExecutionPolicy Bypass -File dev\build.ps1
```
